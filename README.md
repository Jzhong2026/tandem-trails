# Tandem Trails · 亲子协作大冒险

家长和孩子各用一台设备，在浏览器里一起过关。两人各控制一支桨，单桨调整方向，双桨一起前进。首页另有无需联机的横版闯关游戏「星芽大冒险」，可单人或同屏双人游玩，以及支持 1–4 人联机的答题竞速游戏「知识赛车」。

## 星芽大冒险（单人 / 同屏双人）

超级玛丽式的横版闯关：跑、跳、踩敌人、顶问号砖、吃蘑菇长大、拿火花花射火球、踩弹簧飞上天，最后摸到旗杆过关。共 **12 个手绘主题关卡**，分四个世界，全部用 Canvas 矢量绘制，带视差背景、天气粒子、芯片音乐与音效。

| 世界 | 关卡 |
| --- | --- |
| 第一世界 · 晨光草原 | 绿野第一步 · 蘑菇丘陵 · 金币洞窟 |
| 第二世界 · 云端奇旅 | 云端阶梯 · 流沙遗迹 · 霜糖滑道 |
| 第三世界 · 秘境巡游 | 糖果传送带 · 泡泡浅海 · 萤火夜林 |
| 第四世界 · 菇霸决战 | 熔岩要塞 · 彩虹天桥 · 菇霸城堡 |

难度刻意做得轻松：长按跳得更高、轻点小跳，离地后仍有 130ms 起跳宽限；掉进坑里**不扣心**，直接回到最近的存档旗；岩浆和尖刺会扣一颗心；心扣光才重来本关。选关地图里可开启「轻松模式」（心永不扣光）与「自由选关」。进度、星星与最佳记录存在浏览器本地。

**双人同屏更容易通关**，两人分工互补：

- **P1 前锋 · 芽芽**：`A/D` 移动、`W` 跳、`G` 加速、`F` 冲刺击（撞到敌人直接清掉；吃到火花花后改为射火球）。负责开路。
- **P2 后卫 · 豆豆**：`←/→` 移动、`↑` 跳、`.` 加速、`,` 展开守护罩。背上的盾会自动把身后敌人弹开并眩晕，眩晕的敌人碰一下就碎。负责断后。

双人额外的宽松规则：敌人速度降到 82%、菇霸头晕更久；守护罩内两人都无敌；心扣光只变成泡泡，搭档碰一下就复活，两人都变泡泡才重来；每面存档旗全队 +1 心并多送一颗红心；两人靠近触发同行光环，金币双倍；踩搭档头顶可以接力超级跳；掉队会被自动带上；无敌星分给搭档一半时间。后方还会定期出现追兵，正好交给后卫处理。

单人键盘：`←/→` 或 `A/D` 移动，`空格` 跳，`Shift` 加速，`F` 冲刺击 / 火球，`↓` 下蹲，`Esc` 暂停，`R` 重玩。手机和平板会自动显示触屏按键，双人时左右各一组。顶部有一个静音开关，可一次关掉全部音乐与音效。

这一部分完全在浏览器本地运行，不需要联机服务。

## 知识赛车（单人 / 最多 4 人联机）

把二年级上学期的知识问答开成一场赛车比赛：每人一台设备加入同一个房间，各自跑自己的三车道赛道，顶部实时显示所有人的**进度条**和**油箱格数**。

- **服务区答题**：每经过一个服务区停下答 **4 道题**（部编版二上语文 + 北师大版二上数学混合，共 95 题，含答后解析）。答对一题 **+1 格油**，满格 10。
- **油耗**：每经过一个服务区消耗 **3 格油**（答完题出站时扣）；路上撞障碍一次漏 **1 格油**。油箱降到 0 立即淘汰。
- **胜负**：坚持到终点即完赛，按冲线先后排名；结算同时列出「到达终点」和「中途淘汰」两份名单。
- **互不干扰**：有人进站答题时其他车继续跑，只在自己的画面里答题；掉线超过保留期会被判淘汰，不影响别人。

三条主题赛道（阳光校园线 / 黄昏郊野线 / 星空峡谷线）车速与障碍密度递增，房主可在准备时选择赛道和出发油量（默认 6 格）。键盘 `↑/W`、`↓/S` 变道，答题用 `1~4` 选择、`回车` 继续；手机和平板自动显示触屏变道键。顶部有静音开关。

这部分复用联机房间服务（独立 4 席房间与 `race:*` 协议），需要按下面「在家联机」启动服务后游玩；一个人建房即可单人练手。

## 双桨救援队

| 关卡 | 怎么配合 |
| --- | --- |
| 练桨池 | 轮流单独试一次桨，再沿浮标一起划到码头 |
| 浮木弯道 | 一人报方向，另一人配合划桨，绕过两段浮木后接小鸭回岸。水流带会把船推偏，要双桨一起顶住；一段浮木上下漂移，看准节奏再过 |
| 雾里找码头 | 左桨看到救援旗形，右桨看到安全水路。两人各点一次「告诉队友」，一起过雾，再到对应旗子的码头接小鸭 |

房主可在准备时选择关卡。新房间从练桨池开始。通关后可重玩，或在同一个房间进入下一关。

## 萤火虫矿洞

房主选择「萤火虫矿洞」即可游玩首关「断桥接力」。下层玩家按住绿色开关给上层放桥。上层过桥后，按住橙色开关把下层队友升上来。两人各收集自己路线上的萤火虫，一起到出口才通关。机关松开时，桥上的队友和升降台会原地等待，继续按住即可接着走。

第二关「双桥接力」换两人互相帮忙：下层先按住绿色开关放第一道桥让上层过；上层过桥后，按住橙色开关放第二道桥让下层过。每人各收一只自己路线上的萤火虫，一起到出口才通关。通关首关后可在同一个房间点「下一关」进入。

第二关末段还有一道矿车缺口：上层站上车，下层按住蓝色开关送队友过缺口；下层出口前的水晶门认光，两只萤火虫都到才开。所以顺序是「拿灯 → 回开关 → 送队友 → 再过门」，少不了互相喊话。

触屏可以按住页面按钮移动和操作机关。键盘用 **A / D** 移动，**E** 操作机关。

## 摇摇晃晃送龙蛋

房主选择「摇摇晃晃送龙蛋」进入首关「双坡运蛋」。两人各抬担架一端，同时朝同一方向走。上坡时左端按住抬担架，下坡时换右端。担架失衡时可以停下来，等队友把低的一端抬平。龙蛋滑落后会回到软垫，继续运送。

第二关「风口栈道」在坡道之间加了两段风口：坡道仍由较低的一端抬高，风口则必须两人一起按住扶稳，才能顶风慢慢走过，一个人扶不住。风口前也铺了软垫，滑落会从那里重试。通关首关后可在同一个房间点「下一关」进入。

「风口栈道」的风会每隔几秒变向：迎风的那一端按住抬高、背风的一端松开，担架才稳；两人同按反而打滑。看流线方向报给搭档，轮流抬。两段风口之间还有一小段冰面，松手不会立刻停，点按方向键别长按。

触屏用方向按钮和「按住抬高担架」。键盘用 **A / D** 移动，**E** 抬高自己的一端。

## 泡泡潜艇

房主选择「泡泡潜艇」进入首关「珊瑚浅滩」。两人共乘一艘潜艇：左驾驶员只管上浮/下潜，右驾驶员只管前进/后退，谁也代替不了谁，要一直商量着开。先下潜绕过垂下的礁石收集低处气泡，再上浮绕过站立的礁石收集高处气泡，穿过石缝接上小海马，一起开到珊瑚站才通关。碰到礁石会回到最近的浮标，已收集的气泡不会丢。

中途有两带洋流：不顶住对应方向就会把艇推偏。石缝前还有一道触手门，一开一合按固定节奏缩回伸出，闭着时撞上去会回浮标——看准开启窗口，喊「现在」再冲。

触屏用「上浮 / 下潜」或「后退 / 前进」按钮。键盘用 **A / D** 控制自己负责的轴。

## 自选形象与委托剧情

大厅里每个席位是一张形象卡：预览小人 + 名字 + 职责 + 准备状态。自己席位可以选**物种**（小芽人 / 小熊 / 小狐 / 企鹅）、**6 套配色**、**体型**（家长·大 / 孩子·小）和**名字**（最多 8 字）。选择实时同步到搭档设备，按席位存在浏览器本地，掉线重连后保留。四个章节共用同一套角色骨架：脸、四肢、走路/划桨/抬担架/舱内半身姿态，再按章节戴职业装（水手帽 / 矿灯安全帽 / 护蛋背带 / 潜艇耳机）。

剧情是一条贯穿四章的委托线：站长獭獭派单，每章开头是求助者的任务卡（要做什么、为什么必须两个人），局内 NPC 气泡随进度说话并刻意制造信息差（报方向、报深度、报风向、喊「现在」），结算时交代故事结果并递出下一封委托。

## 在家联机

安装 Node.js 24 LTS，然后在项目根目录运行：

```sh
npm ci
npm run build
npm start
```

在运行服务的电脑上，通过 [本机游戏地址](http://localhost:3000/) 进入大厅。直接打开磁盘上的 `index.html` 会显示启动指引。

1. 两台设备连到同一个能相互访问的局域网。用终端打印的 `LAN` 地址在两台设备上打开游戏。终端若列出多个地址，选与手机或平板处在同一网段的地址。
2. 一人创建房间，另一人打开邀请链接，或在同一个地址输入 6 位房间码。选好关卡后，两人分别点击准备。
3. 按住页面上的桨按钮，也可以用空格键。松开就停。先用单桨把船头对准浮标，再并排划向目标。

房间是匿名的。掉线后原标签页在 90 秒内可自动重连，刷新同一页也能恢复。主动退出或服务器重启后，双方重新建房。如果只在主机上能打开，检查系统防火墙的 TCP 3000 入站设置，以及 Wi-Fi 是否隔离设备。HTTP 局域网地址上的剪贴板访问由浏览器决定，页面也提供手动复制和房间码。

## 开发与验证

```sh
npm run dev
npm test
npx playwright install chromium
npm run test:e2e
```

开发入口为 Vite 的 5173 端口，转发联机请求到 3000。生产入口默认绑定所有 IPv4 网卡的 3000 端口，可用 `HOST` 和 `PORT` 环境变量更改。桌面本机入口是 `http://localhost:3000`，健康检查为 `GET /health`。生产反向代理需同时支持轮询、WebSocket 升级，并保留原始 Host。

- `src/shared` 定义房间协议、河道规则，以及 `quest.ts` / `quest-levels.ts` 闯关引擎与 12 关数据。
- `src/server` 管理席位、掉线保留、输入及权威模拟。
- `src/web` 提供大厅、邀请、触屏操作和 Canvas 场景；`quest-*` 为星芽大冒险的美术、渲染、音效、选关与游玩界面。
- 测试使用真实 Socket.IO 客户端和独立的桌面、手机尺寸浏览器上下文。`tests/quest.test.ts` 覆盖物理、道具、双人角色配合，并用自动机器人逐关验证单人与双人都能通关。家庭内测需覆盖两台实体设备和不同家庭网络。

## 发布路线

先完成同网家庭内测，再做 HTTPS 和公网邀请。之后根据家庭试玩数据完善双桨章节，准备中英文内容和推广素材，再扩展送龙蛋与萤火虫矿洞。
