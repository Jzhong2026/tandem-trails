# 浮木弯道联机实现计划

**目标**

玩家从两台设备加入同一个房间并完成一次双桨救援。

**架构**

`src/shared` 定义数据协议、河道和纯规则，`src/server` 管理房间和权威模拟，`src/web` 实现游戏界面和输入。生产启动时由同一个 HTTP 服务提供页面和 Socket.IO。

**技术栈**

Node.js 24 LTS、TypeScript、Socket.IO、React、Vite、Canvas 2D、Node 测试运行器、Playwright。

**设计**

见 [产品与技术设计](../specs/2026-11-18-tandem-trails-design.md)。

## 第一段开发

- [x] 定义河道数据、输入和快照。用固定步长的规则测试验证单桨转向、双桨推进、碰撞回位、接鸭及到岸。
- [x] 实现建房、凭码加入、双人就绪开局、输入租约、断线恢复及重玩。集成测试用真实 Socket.IO 客户端验证不同房间隔离、满员、失效令牌和重复请求。
- [x] 实现可分享的大厅、席位状态、触屏与键盘、关卡反馈及结算。使用桌面与手机尺寸的独立浏览器上下文走通邀请、重连、通关及重玩。
- [x] 验证生产构建，以及主机通过其局域网 IP 建房、分享和联机。将实体双设备和跨网验证列入后续里程碑。

需要格外验证的场景是第二人未准备、短暂掉线、松开事件没送达、刷新恢复身份、分享 API 在 HTTP 下不可用、满员以及房间已不存在。每种情况有独立的可见结果或恢复路径。
