# Tandem Trails 产品与技术设计

## 产品目标

让家长和孩子分别用一台手机、平板或电脑，一起完成一段短冒险。每个人都有另一方无法代劳的操作或线索。关卡允许停下来商量，碰撞后在近处继续。第一版通过浏览器加入私密双人房间，家庭内测先用局域网。

首个交付是《双桨救援队》的「浮木弯道」。创建房间、邀请、各自准备、绕过两段浮木、接小鸭、靠岸、重玩和掉线恢复都走正式的客户端和服务端路径。家长和孩子任选左右桨。默认中文，第一关覆盖触屏和键盘。

## 技术选型

| 路线 | 适用条件 | 取舍 |
| --- | --- | --- |
| **Web + Node.js 24 LTS + Socket.IO** | 需要扫码或点链接即玩，关卡是轻量 2D 玩法 | 一套 TypeScript 覆盖协议和模拟，客户端采用 React、Vite 和 Canvas 2D，短期可在单进程中部署与调试 |
| Web + Colyseus | 房间类型、状态同步和多节点需求已明确 | 获得游戏房间框架的能力，也需要采用框架的生命周期和状态模型 |
| Godot 导出 Web / 原生 | 玩法依赖关卡编辑器、资源管线或复杂表现 | 编辑器利于内容制作，首发还要维护 Web 导出与多人房间服务 |

采用第一条路线。Node.js 使用仓库已具备的 24 LTS 主版本，并通过锁文件固定依赖。Vite 构建浏览器应用，Node.js 同源提供静态文件和 Socket.IO。Canvas 2D 负责场景，房间、操作按钮和反馈用 DOM，支持键盘焦点、屏幕阅读器及移动端触屏。后续若确实需要编辑器或 GPU 渲染，可以替换场景实现，保留房间协议和关卡规则。

## 房间和同步

- 房间码用于邀请，随机会话令牌用于认领已加入的席位。令牌通过响应发给对应客户端，暂存在同一标签页，分享链接只含房间码。服务端绑定连接与席位，并校验所有输入。
- 两人都准备后开始。各自只能控制一支桨。一人按住时船转向，两人按住时沿船头方向前进。放开即可停下来。服务端固定步长 30 Hz 运行规则，约 15 Hz 下发快照。输入带短期租约，客户端每 100 ms 刷新按住状态，失焦时释放。
- 两人都连着才推进模拟。网络中断后保留座位 90 秒，暂停船和计时。重新连接后凭令牌恢复座位与当前关卡状态，双方重新按桨。每场胜利后回到同一房间，可再次准备。
- 服务器独立管理房间生命周期。房间经过 30 分钟无操作后回收。满员拒绝加入，主动退出结束该房间，双方可以重新建房。首版用内存保存房间，服务重启后重新建房。
- 按压状态是可丢的实时消息，过期自动清零。建房、加入、准备、退出使用确认回复。房间事件与连接分离，全量状态可用于重新同步。公网多实例时，同一房间的模拟需要路由到同一个所有者，广播适配器本身无法迁移模拟状态。

## 关卡及发布路线

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 第一段 | 浮木弯道。两段障碍、碰撞回检查点、接鸭、到岸 | 两个独立浏览器能从建房玩到结算。触屏和键盘都能放开即停，暂时断线后继续 |
| 家庭内测 | 练桨池、雾里找码头。增加双端线索、图形提示、画面反馈和角色轮换 | 儿童能自主报告线索和指挥转向。雾里关卡只向对应席位发各自的线索 |
| 邀请制公网测试 | HTTPS/WSS、自定义域、部署与回滚、按来源和房间限制请求、故障观测 | 独立网络可通过链接加入，移动网络切换后可恢复，依据压测确定容量和托管成本 |
| 公共推广 | 双桨救援队完整章节、中英文、原创美术与音频、邀请页及发布素材 | 核验素材授权、儿童隐私、可访问性和多平台兼容。验证玩家能进房以及两个人都能参与 |
| 内容扩展 | 搬龙蛋、萤火虫矿洞。按内测结果决定顺序 | 新玩法沿用席位与生命周期，规则和关卡数据可以独立测试 |

首轮体验重点记录加入成功率、首关完成率和重连恢复率。内测另观察孩子是否会主动发出指令、家长是否愿意停下来等。默认采用私密邀请和匿名席位。公开上线前确认目标市场需要的隐私说明与数据保留策略。

## 可见结果与恢复

| 触发 | 玩家看到什么 | 处理理由 | 恢复 |
| --- | --- | --- | --- |
| 无法访问同网主机或服务器无响应 | 连接失败提示，保留输入的房间码 | Socket 连接是联机前提 | 检查地址、同网互访与防火墙，重新连接 |
| 房间码无效、满员或已关闭 | 具体原因，继续留在大厅 | 双人席位需要验证 | 重新输入或创建房间 |
| 邀请链接复制被浏览器拒绝 | 显示可手动选择的地址和房间码 | 剪贴板只是便捷入口 | 手动分享或直接报房间码 |
| 只有一人准备或另一人尚未加入 | 两席各自的准备状态 | 避免单方面开局 | 等待同伴、取消准备或退出 |
| 实时输入中断、窗口失焦 | 划桨状态松开 | 防止船在陈旧控制下继续走 | 回到页面重新按 |
| 队友断线 | 暂停提示，保留当前进度 | 两人都参与才推进 | 90 秒内自动恢复，该期限过后提示房间关闭 |
| 碰撞浮木或暂时错过小鸭 | 回最近的检查点，或在小鸭附近继续转向 | 防止轻微操作失误破坏整轮体验 | 重新配合转向 |
| 房间已过期或服务重启 | 房间关闭或无法恢复提示 | 内存房间不可恢复 | 一方重新建房并发邀请 |
