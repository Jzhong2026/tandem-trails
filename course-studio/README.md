# 沪上动画课堂

独立运行的上海二至六年级语文、数学和英语课程书架。选年级、学科和上下册，打开课题即可观看原创 SVG 动画、听旁白、看同步字幕并做随堂练习。六年级按上海五四学制的初中预备年级编排。

## 启动

安装 Node.js 24 或更高版本，从仓库根目录运行：

```powershell
npm --prefix course-studio start
```

在浏览器打开 <http://127.0.0.1:4326/>。也可直接运行 `node course-studio/server.mjs`。日常使用无需安装 npm 依赖、FFmpeg 或语音包。每一课的 MP3 已随项目提供，原创课可在本机离线播放。

## 课程与教材

本版共 951 节原创微课、2,853 幕动画和 951 道随堂题。各年级栏内数字依次为上册和下册。

| 学科 | 二年级 | 三年级 | 四年级 | 五年级 | 六年级 | 合计 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 语文 | 38 / 40 | 52 / 53 | 54 / 57 | 50 / 79 | 51 / 50 | 524 |
| 数学 | 18 / 17 | 23 / 23 | 21 / 22 | 29 / 23 | 33 / 21 | 230 |
| 英语 | 14 / 10 | 11 / 34 | 11 / 40 | 11 / 38 | 16 / 12 | 197 |

三至五年级英语下册的节数包含牛津上海版和新世纪版，可在书架选择学校使用的教材。语文覆盖编号课文及各册栏目，语文园地选取代表性任务。数学按新授课题编排，英语按编号单元和表达任务编排。

“原创动画课”按教材的课文、课题或英语单元组织，由三段旁白、分镜板书及一道带解析的练习组成。动画跟随实际音轨时间，可暂停、重播、跳转分镜和调速。数学分数、乘法点阵与数轴按算式绘制。英语用词卡与例句跟读，语文从课文线索进入阅读和表达练习。

“上海空中课堂”收录上海智慧教育平台在这 30 个年级、学期、学科组合下返回的 1,838 个公开课时详情入口，可联网前往官方平台观看。官方资源和原创课程采用各自的课时划分。官方平台资源涉及多个录制年份，各册的版本选择、过渡情况与可核实范围见：

- [语文教材与课程依据](content/chinese-sources.md)
- [数学教材与课程依据](content/math-sources.md)
- [英语教材与课程依据](content/english-sources.md)

上册参考 2026 年秋季已公布教材，下册采用可查的已发行版本。学校使用的教材名称及年份可与上述说明核对。

## 独立数据库

首次启动会创建 `course-studio/data/courses.sqlite`，从本目录的 `content/` 导入原创课。SQLite 保存每节课的脚本、题目，以及每位学习者的续播位置、看完状态和答题达标状态。学习者由浏览器的持久 Cookie 区分。同一浏览器再次打开可继续学习。使用 SQLite WAL 模式，备份时先停止服务，或使用 SQLite 在线备份工具。

可通过 `COURSE_HOST`、`COURSE_PORT` 和 `COURSE_DB` 配置监听地址、端口和数据库路径。默认仅监听本机。家庭局域网使用时，在 PowerShell 中设置 `$env:COURSE_HOST='0.0.0.0'` 后启动，其他设备使用这台电脑的局域网地址和端口访问。

## 维护和核验

```powershell
npm --prefix course-studio run check
```

检查会遍历每一册、每节课、选项与答案、全部 MP3 帧、字幕时间点、脚本指纹和官方入口结构，并打印分册课数与旁白总时长。

`public/` 为播放器与动画绘制代码。`media/` 为旁白和同步索引。修改脚本的 `say` 字段后，用安装了 `edge-tts==7.3.1` 的 Python 环境联网运行 `python -B course-studio/tools/narrate.py`，然后再执行核验并重启服务。生成器跳过已有且指纹相同的音频。合成过程中的暂存文件写入仓库根目录 `tmp/course-narration/`。
